# 验收记录入口

本目录保存某次实际执行的结果与证据，不定义当前业务规则，也不把历史PASS自动用于当前工作树。执行纪律、层级状态和汇总仅见[AGENTS.md](../../AGENTS.md)；任务与预期引用[当前验收清单](../requirements/acceptance-checklist.md)及其REQ版本。

- [2026-09-11证据复核](evidence-review-2026-09-11.md)：只复核已有报告，不补跑产品测试。
- [2026-09-14历史导入定向验证](history-import-2026-09-14.md)：记录历史完成项目、编号和预算修正的分层证据。
- [2026-09-14项目列表年份列与排序定向验证](project-list-years-2026-09-14.md)：记录独立年份列、稳定排序和外部条件状态色的分层证据。
- [2026-09-14项目列表与零预置定向验证](project-list-zero-presets-2026-09-14.md)：记录空模板库、显式实例生成、主流程摘要、筛选候选项和最新动态的定向证据。
- [2026-09-15 Stage直接推进定向验证](stage-direct-advance-2026-09-15.md)：记录直接推进、原子阻塞、立项文件展示及受保护的浏览器验证边界。
- [2026-09-16 Phase 3年度资金与正式分配定向验证](phase-3-funding-2026-09-16.md)：记录资金安排、正式分配与导入的 API 证据及待执行的浏览器写操作。
- [2026-09-19 合同与验收定向验证](phase-4-contracts-2026-09-19.md)：记录合同领域 API 与构建证据，以及尚待执行的浏览器交互验收。
- [2026-09-22 工作台列表与阶段跟踪收敛定向验证](ui-list-stage-convergence-2026-09-22.md)：记录本轮排序、列集、表头/阶段标题选择及详情独立字段证据；完整视口矩阵仍待阶段回归。
- [Phase 1历史执行](phase-1-regression.md)、[Phase 2历史执行](phase-2-external-constraint.md)、[视口历史执行](viewport-regression.md)：原事实保留，旧使用规则不再作为当前规范。
- [本次文档整改结果](../requirements/governance-remediation-2026-09-11.md)：结构检查及只读保护证据，不是产品回归结果。

后续每次执行记录使用独立日期/运行标识，至少填写：

| 字段 | 填写内容 |
| --- | --- |
| 日期/运行标识 | 实际执行时间及本次唯一标识 |
| 需求/验收版本 | REQ-…@vN及AC-… |
| 代码版本 | commit及dirty状态，必要时补diff摘要或指纹 |
| 环境与对象 | API/浏览器环境、隔离数据前缀及前置条件 |
| 步骤/观察 | 实际操作、可观察结果和偏差 |
| 分层结果 | 每个所需层级的状态与证据路径 |
| 总体结果 | 按AGENTS汇总，不跨层推定 |
| 障碍/待办 | BLOCKED写证据和解除条件，尚未执行写NOT_RUN |

不要覆盖前次失败或执行障碍；在新记录中说明后续复测/复核的证据和适用版本。
