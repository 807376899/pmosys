# PMOSYS Figma 交互画板

`pmo-workbench-activity-canvas.svg` 是依据当前前端工作台结构制作的 Figma Design 画板：它覆盖总览、阶段跟踪、办理活动上下文和成员管理模式。

## 导入

1. 在 Figma Design 新建文件。
2. 将 `pmo-workbench-activity-canvas.svg` 直接拖入画布。
3. 在 Layers 中展开 `01-overview`、`02-stage-tracking`、`03-activity-context`、`04-member-management` 四个分组；复制并拆分这些分组后，即可连成可点击原型。

SVG 以文本和基础矢量形状组成，适合修改结构、文案、颜色、间距和交互路径；它不是不可编辑的运行页面截图，也不包含测试库中的项目名称或金额。

## 建议先调整的交互

- 总览和阶段跟踪之间的切换；右侧“推进管理”与“办理活动”两个独立入口。
- 事项单元格的单项目快速办理，与事项列选择后的批量办理之间的边界。
- “安排办理活动”中新建与加入已有活动的流程。
- 办理活动中“记录本次办理结果”和“完成事项”两条独立动作。
- 成员管理模式与普通勾选模式之间的视觉与返回路径。

此设计资产不修改产品代码、数据库或业务规则。若需要将 SVG 直接发布到团队的 Figma 文件，需要在 Codex 中连接可写入的 Figma 集成；当前环境未提供该连接器。
